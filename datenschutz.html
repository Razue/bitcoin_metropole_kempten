Dabei kann eine Übermittlung in ein Land außerhalb der EU/des EWR stattfinden. FormSubmit leitet die Anfrage als E-Mail an bitcoinmetropole@proton.me weiter. Dieses Postfach wird bei Proton gehostet.

Speicherdauer: Deine Anfrage wird so lange gespeichert, wie es für die Bearbeitung und Dokumentation erforderlich ist. Auf Wunsch löschen wir sie jederzeit – schreib uns einfach eine E-Mail.

Deine Rechte: Es gelten deine Rechte aus Abschnitt 5. Du kannst die Löschung deiner Anfrage jederzeit per E-Mail verlangen. Alternativ kannst du uns auch ohne das Formular direkt per E-Mail schreiben.

Ticketbestellung: Wenn du ein Ticket sicherst, werden dein Name bzw. Pseudonym, deine E-Mail-Adresse (freiwillig) und die Anzahl der Tickets an unseren Ticket-Server (tickets.lernbitcoin.com) übertragen und dort zur Abwicklung deiner Bestellung gespeichert. Falls du on-chain bezahlst, werden Transaktionsdaten dauerhaft und öffentlich auf der Bitcoin-Blockchain gespeichert; eine Löschung ist technisch nicht möglich.

Speicherdauer: Die Bestelldaten werden so lange gespeichert, wie es für die Abwicklung und Dokumentation erforderlich ist.

Video: Das eingebundene allgäu.tv-Video wird von demselben Server (tickets.lernbitcoin.com) bereitgestellt. Es wird erst geladen, wenn du auf „Play“ klickst. Dabei wird deine IP-Adresse an diesen Server übermittelt.
